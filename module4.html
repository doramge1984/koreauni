무엇을 · 왜 · 어떻게

코드를 외우지 않아도 됩니다. Gemini에게 코드를 만들어달라고 시키고, 그 코드를 붙여 넣으면 끝입니다. "내가 만든 로봇이 실제로 일하는 모습"을 눈으로 확인하는 것 — 그 경험이 오늘의 목표입니다.

💡 모듈 3에서 만난 앱스 스크립트(Apps Script), 기억나죠? 그땐 데이터를 '읽어서 내보내는(API)' 용도였고, 이번엔 폼 제출에 자동으로 반응해 일하는(트리거) 용도예요. 같은 도구, 다른 초능력! 🤖
🎯

무엇을 (What)

MT 폼 응답 → 맞춤 추억 엽서 PDF 자동 생성 → 신청자 이메일 자동 발송 → 커피 추첨 응모번호 자동 부여. 사람 손 없이 한 번에.

💡

왜 (Why)

50명 MT가 끝난 뒤 한 명 한 명 메일 보내기, 응모번호 관리하기 — 이 반복 작업을 AI·자동화에게 맡기는 첫 성공 경험을 만들기 위해서.

🔧

어떻게 (How)

구글 워크스페이스 안에서 Apps Script 한 벌과 트리거 하나로. 설치·결제 없이 누구나 따라 할 수 있게. Gemini가 코드를 써줍니다.

메시지

왜 지금 "자동화"인가

MT 뒤처리는 사실 거창한 일이 아닙니다. 그런데 이 작은 반복 업무가 가장 먼저 자동화되어야 할 것들입니다.

과대표·총무가 MT 후에 하는 일을 떠올려 보세요

참가자 50명 명단 확인 → 각자 이름 불러서 메일 초안 작성 → 첨부파일 붙이기 → 한 명씩 발송 → 응모번호 엑셀 관리 → 추첨까지.

사람이 하면 지치고 실수하지만, 한 번 자동화해두면 24시간, 실수 없이, 똑같이 일합니다. 심지어 여러 명이 동시에 제출해도 응모번호가 겹치지 않습니다.

오늘 여러분은 이 시스템을 직접 손으로 한 번 만들어 봅니다. 완성 후엔 동아리 신입 모집, 행사 응모, 방명록 — 어디든 그대로 가져다 쓸 수 있습니다. 진짜 핵심은 코딩 실력이 아니라 "이 반복은 자동화할 수 있다"는 눈이에요.

왜 지금, '자동화'가 가장 강력한 무기일까

우리가 하는 일의 많은 부분은 거창한 시스템이 아니라, 매번 손으로 반복하는 잔업으로 채워져 있어요. 같은 양식 수십 개 만들기, 응답 받아 정리하기, 한 명 한 명에게 메일 보내기 — 사람이 하면 지치고 실수하지만, 한 번 자동화해두면 24시간, 실수 없이, 똑같이 일합니다.

그래서 진짜 핵심은 코딩 실력이 아니라 "이 반복은 자동화에게 맡길 수 있다"는 눈이에요. 작은 일부터 AI 에이전트에게 시켜본 경험이 쌓이면, 결국 더 큰 업무 흐름도 스스로 설계하게 됩니다.

그리고 이건 지금 가장 필요한 역량이기도 해요. 기업이 채용에서 보는 'AI 활용 능력'의 핵심이 바로 이것 — 반복 업무를 스스로 자동화하는 힘이거든요. AI 에이전트 시대엔 일을 빨리 하는 사람보다 '사람 없이 돌아가는 시스템'을 만드는 사람이 앞서갑니다.

⏱ 반복 업무 시간 절약 🎯 사람의 실수 제거 💼 채용이 보는 'AI 활용 역량' 🤖 AI 에이전트 시대 ⚙️ 반복을 시스템으로

직접 체험

먼저, 내 엽서를 직접 받아보기

시스템을 만들기 전에, 여러분이 먼저 '참여자'가 되어 봅니다. 체험 폼에 MT 소감을 적고 사진을 올려 신청하면 잠시 후 메일함에 내 이름·사진·커피 응모번호가 박힌 추억 엽서가 도착해요. 이걸 경험한 뒤, 아래 실습에서 직접 이 시스템을 만듭니다.

✈

체험 순서

  1. 아래 체험 폼 열기 버튼을 누릅니다.
  2. 메일 주소 · 이름 · MT 소감을 입력하고, 사진 한 장을 첨부한 뒤 제출합니다.
  3. 잠시 후 메일함을 확인합니다 — 엽서가 도착했나요?
  4. 받은 엽서에 내 이름·사진·커피 응모번호가 잘 들어갔는지 확인합니다.

실습 — 6단계로 시스템 만들기

각 단계를 완료하면 ✅ 버튼을 눌러 체크하세요. 순서대로 따라오면 자동화 시스템이 완성됩니다.

1

슬라이드 엽서 템플릿 만들기

▾

엽서 디자인 배경 위에 텍스트박스와 사진 도형을 올려 템플릿을 만듭니다. 시간이 부족하면 아래 '사본 만들기'로 완성 템플릿을 내 드라이브에 복사해서 바로 쓰면 됩니다.

📑 엽서 템플릿 사본 만들기
📖 직접 만드는 방법 (열어보기)
  1. slides.google.com에서 새 프레젠테이션 열기
  2. 슬라이드 오른쪽 클릭 → 배경 변경 → 이미지 → 준비된 엽서 PNG 업로드
  3. 텍스트박스 3개 삽입 (삽입 → 텍스트박스). 정확히 아래 문자열로 입력:
필수 텍스트 표식 (이 문자열 그대로 — 띄어쓰기 포함)
{{이름}}   {{소감}}   {{응모번호}}
  1. 사진 자리 도형 삽입 → 삽입 → 도형 → 직사각형 (사진이 들어갈 크기로)
  2. 주소창에서 TEMPLATE_ID 복사 후 메모장에 저장
📌 주소창 형식: https://docs.google.com/presentation/d/[TEMPLATE_ID]/edit
/d/ 뒤 ~ /edit 앞 문자열이 TEMPLATE_ID입니다.

📂 제출하면 어디에 저장되나요?
제출 데이터는 세 곳에 나뉘어 저장돼요 👇

• 답변(텍스트) → 응답 시트 — 이메일·이름·소감이 방금 연결한 구글 시트에 한 행씩 쌓여요. (폼 '응답' 탭에서도 볼 수 있어요.)
• 업로드한 사진 → 내 드라이브 — 시트엔 '파일 링크'만 들어가고, 실제 사진은 내 드라이브에 자동 생성되는 [폼 제목] (파일 응답) 폴더에 저장돼요. (그래서 슬라이드를 공유 안 해도 스크립트가 사진을 바로 읽어요.)
• 완성 엽서 PDF → 내 출력 폴더 — 제출 순간 트리거가 코드를 실행해 엽서 PDF를 2단계에서 만든 결과물 폴더(FOLDER_ID)에 저장하고, 동시에 신청자 이메일로 보내요.
✨

코드를 못 짜도 괜찮아요 — Gemini로 코드 만들기

아래 프롬프트를 Gemini에 그대로 붙여넣으면, 4단계에 들어갈 Apps Script 코드를 거의 완성된 형태로 만들어 줍니다. "AI에게 시켜서 자동화 코드를 받아오는" 경험 그 자체예요.

구글 폼이 제출되면 슬라이드 템플릿을 복사해 {{이름}}과 {{소감}} 항목을 채우고, 대체 텍스트(제목 또는 설명)가 '사진자리'인 도형을 사용자가 업로드한 사진 파일로 바꾼 뒤, PDF로 변환하여 신청자에게 메일로 자동 발송하는 Apps Script를 만들어줘. [필수 조건] 1. 구글 시트에 데이터가 들어오는 순서대로 고유한 세 자리 응모번호(예: 001, 002...)를 코드가 스스로 계산해서 자동 생성하게 해줘. 동시에 여러 명이 제출해도 번호가 겹치지 않도록 e.range.getRow()를 사용해줘. 2. 그 생성된 응모번호를 슬라이드 템플릿에 있는 {{응모번호}} 표식 자리에 매핑해서 글자가 치환되도록 짜줘. 3. 구글 폼의 질문 명칭은 이메일, 이름, 소감, 사진이며, TEMPLATE_ID와 FOLDER_ID는 코드 상단 변수에서 쉽게 바꿀 수 있게 전역 변수로 분리해줘.
✅ 복사됨!
💡 핵심은 ① 폼 질문 이름(이메일·이름·소감·사진) ② 약속된 표식({{이름}}·{{소감}}·{{응모번호}}·대체 텍스트 사진자리) ③ 최종 결과물(PDF → 메일 + 커피 응모번호)을 빠짐없이 적는 것. 그러면 거의 정확한 코드가 나와요.
🔨 코드가 예상과 다르게 나와도 괜찮아요. 그땐 에러 메시지나 "이 부분이 이렇게 안 돼", "이렇게 바꿔줘"처럼 원하는 바를 AI에게 다시 알려주며 대화하듯 고쳐나가면 됩니다. 오류를 잡는 디버깅 과정도 AI와 함께 하는 거예요. 오늘은 시간 관계상, 미리 완성해 둔 최종 코드를 다음 단계(4단계)에서 다 같이 넣어보겠습니다!

Apps Script에 코드 넣기

▾
  1. 구글 시트 열기 → 상단 확장 프로그램 → Apps Script
  2. 왼쪽 위 '제목 없는 프로젝트'를 눌러 'MT 추억 엽서 + 응모번호 자동 발송 시스템'으로 이름 변경 (나중에 찾기 쉬워요)
  3. 가운데 Code.gs 편집창에서 기존 코드 전부 선택 Ctrl+A → 삭제
    💡 Code.gs가 뭐예요?
    Apps Script를 열면 가운데에 자동으로 뜨는 기본 코드 파일이에요. 바로 이 Code.gs 안에 자동화 코드를 넣으면, 구글이 그 코드를 대신 실행해 줍니다. (.gs는 Google Apps Script 파일의 확장자예요.)
  4. 아래 박스의 '아래 코드에 ID 적용' 버튼을 눌러 내 TEMPLATE_ID·FOLDER_ID를 코드에 채우기 (또는 코드 맨 위 두 줄에 직접 입력)
  5. 완성된 코드(Gemini 생성 코드 또는 ID가 채워진 예시 코드)를 Code.gs에 붙여넣기 → Ctrl+S (또는 상단 💾 저장 아이콘)으로 저장
🔑 1·2단계에서 저장한 내 ID (아래 예시 코드에 넣을 값)
TEMPLATE_ID = — (1단계에서 추출하면 자동 표시)
FOLDER_ID = — (2단계에서 추출하면 자동 표시)

📄 예시 앱스 스크립트(Apps Script) 코드

// =============================================
// ✅ MT 추억 엽서 + 응모번호 자동 발송 시스템
// =============================================
// [사용 전 필수] 아래 두 값을 본인 것으로 교체
const TEMPLATE_ID = 'YOUR_TEMPLATE_SLIDE_ID';
const FOLDER_ID   = 'YOUR_OUTPUT_FOLDER_ID';

function onFormSubmit(e) {

  // 1. 응모번호 생성 (동시 제출 안전)
  // e.range.getRow() = 이 제출이 기록된 행 번호
  // 구글이 행을 확정한 뒤 트리거를 실행하므로 절대 겹치지 않음
  const row      = e.range.getRow();
  const entryNum = String(row - 1).padStart(3, '0');

  // 2. 폼 응답 추출 (질문명이 폼과 정확히 일치해야 함)
  const responses = e.namedValues;
  const email     = responses['이메일'][0].trim();
  const name      = responses['이름'][0].trim();
  const memory    = responses['소감'][0].trim();
  const photoUrls = responses['사진'];

  // 3. 슬라이드 템플릿 복사
  const templateFile = DriveApp.getFileById(TEMPLATE_ID);
  const outputFolder  = DriveApp.getFolderById(FOLDER_ID);
  const copiedFile    = templateFile.makeCopy(`MT추억엽서_${name}_${entryNum}`, outputFolder);
  const presentation  = SlidesApp.openById(copiedFile.getId());
  const slide         = presentation.getSlides()[0];

  // 4. 텍스트 치환
  presentation.replaceAllText('{{이름}}',    name);
  presentation.replaceAllText('{{소감}}',    memory);
  presentation.replaceAllText('{{응모번호}}', `#${entryNum}`);

  // 5. 사진 치환 (대체 텍스트 '사진자리' 도형을 이미지로 교체)
  if (photoUrls && photoUrls[0] && photoUrls[0].trim() !== '') {
    try {
      const photoUrl     = photoUrls[0].trim();
      const photoIdMatch = photoUrl.match(/id=([a-zA-Z0-9_-]+)/) ||
                            photoUrl.match(/\/d\/([a-zA-Z0-9_-]+)/);
      const photoBlob    = DriveApp.getFileById(photoIdMatch[1]).getBlob();
      const elements     = slide.getPageElements();
      for (const el of elements) {
        if (el.getTitle() === '사진자리' || el.getDescription() === '사진자리') {
          const type = el.getPageElementType();
          if (type === SlidesApp.PageElementType.SHAPE)
            el.asShape().replaceWithImage(photoBlob);
          else if (type === SlidesApp.PageElementType.IMAGE)
            el.asImage().replace(photoBlob, true);
          break;
        }
      }
    } catch (err) {
      console.error('사진 로드 실패:', err.message);
    }
  }
  presentation.saveAndClose();

  // 6. PDF 변환 및 메일 발송
  const pdfBlob = DriveApp.getFileById(copiedFile.getId())
    .getAs('application/pdf')
    .setName(`MT추억엽서_${name}_${entryNum}.pdf`);

  GmailApp.sendEmail(email,
    `[MT 추억 엽서] ${name}님의 커피 추첨 응모번호: #${entryNum}`,
    `${name}님, 우리 MT 추억 엽서를 보내드립니다!\n\n` +
    `커피 기프티콘 추첨 응모번호: #${entryNum}\n\n` +
    `추첨 결과는 추후 안내드릴게요. 첨부파일을 확인해 주세요.`,
    { attachments: [pdfBlob] }
  );
}
