🔎 왜 이 순서일까? — 모듈 1→4가 어떻게 이어지는지

① 프로젝트 흐름 — MT의 처음부터 끝까지

준비(1)에서 AI 다루는 기본기를 익히고 → 기획(2)에서 수요조사·안내·프로그램을 설계하고 → 결정(3)에서 모인 응답을 대시보드로 정리해 ‘어디로·언제’를 정하고 → 아카이빙(4)에서 끝난 뒤의 추억을 자동으로 기록해요.

② 기술 흐름 — 갈수록 자동화가 깊어져요

프롬프트 기초(1) → 도구 활용(2) → 앱스 스크립트(Apps Script)로 데이터 읽기·API(3) → 앱스 스크립트(Apps Script)로 자동 반응·트리거(4). 모듈 3·4는 같은 도구(앱스 스크립트(Apps Script)), 다른 초능력이에요 — 3은 데이터를 읽어서 내보내고, 4는 제출에 자동으로 반응하죠.

🔗 모든 걸 잇는 건 ‘구글 폼’이에요. 모듈 2가 폼을 만들고 → 모듈 3이 그 응답을 읽고 → 모듈 4가 새 폼 응답에 반응해요. 즉 만든다 → 읽는다 → 반응한다로 하나의 프로젝트가 관통합니다.
